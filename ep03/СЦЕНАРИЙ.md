# ГИГАНТСКИЕ МУТАНТЫ — Серия 3 «Кафедра»

Утро после серии 2. Ветер, серый рассвет, медфак, подвал кафедры нормальной физиологии.

**Цель Никиты:** вытащить из профессора правду и лекарство для Аси.
**Что может потерять:** Асю — реагент выветрился, серое снова ползёт по шее.
**Что пригождается:** знание медфака (через анатомичку в подвал; при пожаре двери открываются сами), папин пропуск (дверь подвала со знаком завода), зажигалка (датчик дыма), твёрдая рука Аси (отодвигает профессора «как вентиль» — и за это серое растёт).
**Намёки на поворот:** знак завода «Река» на двери кафедры; табло «Орлов. Доступ: донор»; рыбы в аквариумах смотрят, как в реке.
**Поворот:** реагент делают из крови отца Аси — он спит в баке у профессора; ему осталась одна доза, следующий донор — Ася.
**Кто всё скрывал:** профессор Вершинин.
**Обрыв:** на улице Ася оборачивается — глаза у неё зелёные, «как у них».
