# Footage — Alila Seminyak only

Drop real clips/photos of the hotel here, named by slot prefix, then run `python3 build.py`.

| Prefix | Block | Time | What to show |
|---|---|---|---|
| `01_` | Hook | 0–3 s | Widest sunset shot: hotel + ocean / pool |
| `02_` | Pool | 3–7 s | Smooth fly-over of the infinity pool |
| `03_` | Rooms | 7–11 s | Room, terrace, interior details, view |
| `04_` | Beach | 11–15 s | Ocean, waves, Petitenget beach |
| `05_` | Experience | 15–19 s | Spa, Seasalt, table setting (several files allowed: `05a_`, `05b_`) |
| `06_` | Highlight | 19–23 s | Best shot of the hotel (auto slow motion) |

Video (mp4/mov) preferred, vertical or horizontal — it is centre-cropped to 9:16, never stretched.
Each clip should be at least 5 s long. Photos get a slow push-in.
