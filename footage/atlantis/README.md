# Фото для «Отель недели»: Atlantis The Royal (Дубай, Palm Jumeirah)

Положите свои фото в эту папку под такими именами (вертикальные кадры лучше всего, исходного качества, от 1080 px по ширине):

| Файл | Что на кадре |
|---|---|
| `01_cover.jpg` | самый красивый общий вид отеля (башня снаружи или вид с воды/пляжа) |
| `02_cloud22.jpg` | бассейн Cloud 22 на 22 этаже или любой бассейн на высоте |
| `03_pool_suite.jpg` | бассейн в номере или сьюте; если не было, любой бассейн отеля |
| `04_restaurant.jpg` | ресторан, сервировка, блюдо |
| `05_tower.jpg` | архитектура: башня, лобби, фасад |
| `06_palm_view.jpg` | вид на Пальму, залив или город с высоты (из окна, с террасы) |
| `07_beach.jpg` | пляж или бассейн днём |

Сборка: `python3 make_story.py formats/hotel_week_atlantis/config.json`
