# Сайт InVoyage («скоро» + подписка)

Одна страница: фото, подборка «Где тепло в декабре», форма подписки «узнать первыми». Услуги и даты на сайте не заявлены.
Весь сервер на стандартной библиотеке Python: без зависимостей, без внешних скриптов, шрифтов и счётчиков.

## Запуск на своём компьютере
```
cd site && python3 server.py          # http://127.0.0.1:8080
python3 test_security.py              # проверки защиты (должно быть OK)
```

## Запуск в интернете (VPS + свой домен)
1. Купите домен, направьте A-запись на IP сервера. **Сервер лучше взять в России** (хранение персональных данных россиян, 152-ФЗ).
2. На сервере (Docker): `echo "DOMAIN=ваш-домен.ру" > .env && docker compose up -d --build`
3. Caddy сам выпустит HTTPS-сертификат. Откройте только порты 80 и 443 (файрвол).
4. Соцсети на сайте: впишите в `config.json`, затем перезапустите (`docker compose restart app`):
   `{"links": [{"label": "Telegram", "url": "https://t.me/ваш_канал"}, {"label": "Instagram", "url": "https://www.instagram.com/ваш_профиль/"}]}`
   Разрешены только https-ссылки на t.me, instagram.com, youtube.com, tiktok.com.
5. Список подписчиков: `docker compose exec app python3 export_subscribers.py > subscribers.csv`. Копируйте `data/` в резервную копию.

## Что защищено
- **Заголовки**: строгий CSP (только свои файлы, без inline-скриптов и стилей), запрет встраивания (clickjacking), nosniff, no-referrer, HSTS (через HTTPS), запрет камеры/геолокации.
- **Файлы**: белый список расширений, блокировка `..`, точечных и скрытых файлов; наружу отдаётся только папка `public`.
- **Форма**: подпись-токен (CSRF) в cookie и теле, «ловушка по времени» (быстрая отправка отклоняется), скрытое поле-ловушка для ботов, проверка Origin, только JSON до 2 КБ, лимит попыток с одного IP (8 в час) и общий (300 в час).
- **Данные**: SQLite с параметрами (нет SQL-инъекций), адрес в ответе не возвращается, дубликаты не раскрываются, IP хранится только как хеш, файлы данных с правами 600.
- **Сервер**: лимит соединений, таймауты (защита от «медленных» атак), общие страницы ошибок, версия сервера не раскрывается, в логах нет e-mail и параметров запросов.
- **Контейнер**: не root, файловая система только для чтения, все привилегии сброшены, лимиты памяти и процессов.
- Нет админ-панели и входа: список подписчиков выгружается только командой на сервере.

## Что нужно сделать вам (я сделать не могу)
- Купить домен и сервер, запустить по инструкции выше. Я проверила сервер и страницы локально, а Docker-сборку и Caddy в этой среде не запускала.
- Дополнить `public/privacy.html` реквизитами владельца (ИП/организация) и контактом для отзыва согласия. Это требование закона, текст нужно согласовать с юристом.
- Вписать ссылки на соцсети в `config.json`.
- Поставить обновления ОС и Docker, не открывать лишние порты, включить ключевой вход по SSH вместо пароля.
- Ничто не защитит от потери доступа к самому серверу или домену, поэтому включите двухфакторную защиту у регистратора и хостера.
