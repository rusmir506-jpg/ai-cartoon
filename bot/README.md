# Бот InVoyage

Бот-визитка: «Где тепло в декабре», «5 ошибок при выборе отеля», «Как сэкономить», подписка «Узнать первыми».
Услуги и даты открытия в нём не заявлены. Для владельца: `/stats` (сколько подписчиков) и `/broadcast текст` (рассылка с предпросмотром и подтверждением).

## Как запустить
1. В Telegram откройте @BotFather, отправьте `/newbot`, придумайте имя и логин (заканчивается на `bot`). BotFather пришлёт **токен**. Он как пароль: никому не показывайте и не вставляйте в чат.
2. Узнайте свой числовой ID: напишите боту @userinfobot, он ответит числом.
3. На сервере (подойдёт тот же, что для сайта) в папке `bot`:
   ```
   cp .env.example .env && nano .env      # впишите BOT_TOKEN=... и ADMIN_IDS=ваш_ID
   docker compose up -d --build
   docker compose logs -f bot             # должно быть: bot started
   ```
4. Откройте бота в Telegram, нажмите «Старт».
5. По желанию в @BotFather: `/setdescription` (описание бота), `/setuserpic` (логотип), `/setabouttext`. Команды меню бот выставляет сам.

## Рассылка
Отправьте боту `/broadcast Текст сообщения`. Бот покажет предпросмотр и кнопку «Отправить N подписчикам». Пока не нажмёте, ничего не уходит. Получают только те, кто сам согласился. Заблокировавшие бота исключаются автоматически.

## Защита
Токен только в `.env` (в репозиторий не попадает), в логах его нет; бот работает через long polling и не открывает портов; отвечает только в личных чатах; лимит 20 сообщений в минуту на человека; кнопки проверяются по белому списку; тексты пользователей не сохраняются и не возвращаются; хранится только ID чата и время согласия; `/stop` удаляет данные; рассылка идёт обычным текстом с паузами.
Если токен утёк: в @BotFather `/revoke`, затем обновите `.env` и `docker compose up -d`.

## Что учесть
- Telegram API в этой среде недоступен, поэтому я проверила бота тестами с имитацией Telegram (`python3 test_bot.py`) и прогоном цикла опроса на поддельном сервере. С реальным токеном первый запуск делаете вы.
- Подписка на рассылку требует согласия на обработку данных: текст согласия в боте есть, а политику конфиденциальности сайта допишите реквизитами владельца.
